Essential resources and utilities maintained by the OpenELA community, from source archiving to workload migration.

Mothership

The Mothership project is a collection of tools and services to archive RPM package source and attest to their authenticity. It ensures that the source code used to build Enterprise Linux is securely preserved and universally verifiable by the community.

View on GitHub

Leapp

Leapp is an existing open source project that aims to serve as an expert advisor for moving operating systems (OS) workloads to newer Enterprise Linux OS versions by generating suggested actions, identifying risks, producing checklists, and automating steps for users.
